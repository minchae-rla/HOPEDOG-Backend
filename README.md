# 📌 프로젝트 소개

현대 사회에서 반려동물을 가족처럼 여기는 문화가 확산되면서  
유기견 문제와 동물 복지에 대한 관심 또한 지속적으로 증가하고 있습니다.

희멍의 집은 유기견 보호 및 입양 문화를 활성화하기 위해 제작한  
**유기견 입양 · 임시보호 · 봉사 · 후기 공유 커뮤니티 플랫폼**입니다.

사용자들은 커뮤니티를 통해 유기견 관련 정보를 공유하고,  
입양 및 임시보호 활동에 참여할 수 있으며,  
봉사 및 후원 활동을 통해 사회적 책임을 실천할 수 있습니다.

# 🚀 주요 기능

## 🐾 유기견 커뮤니티 게시판

- 입양 게시판
- 임시보호 게시판
- 봉사 게시판
- 후기 게시판

# 📚 프로젝트를 통해 배운 점

### ✔ Spring Security 기반 인증 흐름 이해

회원과 비회원 권한을 분리하며  
실제 서비스에서 사용되는 인증 및 접근 제어 흐름을 경험했습니다.

<br>

### ✔ MyBatis 기반 데이터 처리 경험

SQL 중심의 데이터 처리 및 매핑 구조를 직접 설계하며  
DB 연동에 대한 이해도를 높였습니다.

<br>

### ✔ 협업 프로젝트 경험

GitHub를 통한 형상관리 및 역할 분담을 경험하며  
팀 프로젝트 진행 방식과 협업 프로세스를 학습했습니다.
